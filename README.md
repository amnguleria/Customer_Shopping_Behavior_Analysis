##Customer Behavior Analysis | SQL, Python & Power BI
Project Overview

This project demonstrates an end-to-end data analytics workflow using customer shopping behavior data. The objective is to transform raw data into actionable business insights through data cleaning, analysis, visualization, and reporting.

#Key Tasks
 Data Preparation & Exploratory Analysis (Python)
Imported and explored customer behavior data
Performed data cleaning and preprocessing
Conducted exploratory data analysis (EDA)
Prepared data for database storage
 #Data Analysis (SQL)
Loaded cleaned data into a relational database
Wrote SQL queries to analyze customer behavior
Identified purchasing patterns, customer segments, and key business metrics
Generated insights to support business decision-making
  #Dashboard Development (Power BI)
Connected Power BI to the SQL database
Built an interactive dashboard
Visualized customer trends, spending behavior, and performance metrics
Created business-friendly reports for stakeholders
Tools & Technologies
Python (Pandas, NumPy)
SQL (PostgreSQL/MySQL)
Power BI
Jupyter Notebook
#Outcomes
Developed a complete data analytics workflow from raw data to dashboard reporting
Applied Python for data preparation and SQL for business analysis
